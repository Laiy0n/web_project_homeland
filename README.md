# Tripleten web_project_homeland

## Descrição

Este projeto faz parte do Sprint 5 da TripleTen. A página apresenta a Galeria de Arte TripleTen e fala sobre as origens das pessoas que fazem parte da equipe. O layout foi desenvolvido com base no Figma e adaptado para desktop, tablet e mobile.

A página reúne o logotipo e o título da galeria, uma fotografia da costa, uma citação de Joseph Beuys, um texto de apresentação e o rodapé.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3 com Flexbox e consultas de mídia
- Metodologia BEM Flat
- Fonte Inter carregada localmente
- Normalize.css
